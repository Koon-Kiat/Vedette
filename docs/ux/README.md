# UX working documents

The dashboard's design records: the context, an evaluation with its findings,
and what each fix changed.

- [context-vedette.md](context-vedette.md): who the dashboard is for, the
  constraints and the principles it is held to.
- [evaluation-dashboard.md](evaluation-dashboard.md): findings ranked by
  severity, each with the heuristic it breaks and the change that fixes it.
- [copy-dashboard.md](copy-dashboard.md): the words on the pages, in alerts
  and in the digest, including each rule's plain name.
- [accessibility-dashboard.md](accessibility-dashboard.md),
  [states-dashboard.md](states-dashboard.md),
  [adaptation-narrow-window.md](adaptation-narrow-window.md) and
  [navigation-findings-order.md](navigation-findings-order.md): the fixes, by
  discipline.
- [decisions.md](decisions.md): what was decided, by whom and why.

They cite `PRODUCT.md` and `DESIGN.md`, the product and visual briefs the
design tools read. Those are kept on the owner's machine, not in this
repository; the visual system itself is described under "The dashboard" in
[docs/ARCHITECTURE.md](../ARCHITECTURE.md).
